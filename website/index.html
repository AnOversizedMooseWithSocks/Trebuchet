02 / operations

See what the chain sees.

Trebuchet separates configuration, live evidence, and recovery state so operators can tell what is planned, what landed, and what still needs action.

Live token intelligence

Mint facts, not feed noise.

Inspect a mint against mainnet evidence: token program, metadata, authorities, distribution, concentration, and local Trebuchet provenance.

  • Uses saved mainnet RPC evidence even when the launch environment is devnet.
  • Separates a missing mint from an upstream RPC outage.
  • Keeps the registry local—no social layer, ranking game, or paid placement.
Recovery as a first-class state

A failed step is not a mystery.

The execution journal centralizes safe resume, local wallet custody, audit events, and manual blockers. Recovery wallets live in the recovery workspace—not hidden beneath the active signer.

  • Find → unlock → act → verify workflow with explicit terminal states.
  • Automatic resume only when recorded checkpoints are safe.
  • Final sweep evidence closes the run and its permanent dossier.
